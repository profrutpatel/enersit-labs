## 🛡️ Executive Summary
Enersit Labs builds sovereign, air-gapped, GPU-accelerated Retrieval-Augmented Generation (RAG) and tactical intelligence platforms. The platform runs 100% offline on localized GPU hardware with fine-tuned local open-source LLMs (Qwen3 + LoRA), guaranteeing zero data leaks, zero cloud dependencies, and automated line-by-line claim verification to eliminate hallucinations in high-stakes defense environments.

## ⚡ Key Technical Benchmarks
- **100% Air-Gapped:** Zero cloud telemetry or external API reliance
- **< 1.2s Query Latency:** Hybrid sparse BM25 + dense vector retrieval
- **3.6 GB VRAM Footprint:** 2 model replicas running concurrently on GTX 1650 / CUDA 12.6
- **0.0% Hallucination Rate:** Automated ground-truth OCR claim audit
